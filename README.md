## 🏗️ Architectural Overview
- **Vite 5 + React 18** for fast builds and lightweight bundle
- **Tailwind CSS** with custom architectural color palette:
  - Deep Structural Navy: `#0F2C52`
  - High-Vis Safety Orange: `#E87722`
  - Architectural Steel: `#58595B`
  - Blueprint Stone: `#F6F5F2`
  - Carbon Foundation: `#0B0C0E`
- **Framer Motion** for engineering telemetry micro-interactions and modal transitions
- **Lenis Smooth Scroll** for inertial momentum scrolling
- **DJI Drone Telemetry Integration** (Live flight video reels and 4K aerial survey coordinates)
- **Interactive Project Tendering Dossier** (RFQ system routing directly to WhatsApp `+263 77 515 7802` and Email `office@kaardinvestment.co.zw`)
